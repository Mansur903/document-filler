# UAE Residence Permit Recognition Specification

## Purpose

Позволяет пользователю локально распознавать UAE Residence Permit по выбранному изображению или PDF и получать структурированные реквизиты разрешения на проживание для общей формы и DOCX-шаблонов.

## Requirements

### Requirement: Выбор типа UAE Residence Permit

Система SHALL предоставлять в интерфейсе компактный явный выбор типа документа и SHALL использовать выбранный тип для запуска парсера UAE Residence Permit вместо автоматического определения документа.

#### Scenario: Выбран UAE Residence Permit

- **WHEN** пользователь выбирает тип `UAE Residence Permit`
- **THEN** последующее распознавание выбранного файла использует правила извлечения данных UAE Residence Permit

#### Scenario: Тип документа изменён до распознавания

- **WHEN** пользователь меняет выбранный тип документа после выбора файла, но до запуска распознавания
- **THEN** система использует новый тип документа и не очищает общую форму

### Requirement: Поддерживаемые файлы UAE Residence Permit

Система SHALL позволять выбрать один локальный файл UAE Residence Permit в формате `.jpg`, `.jpeg`, `.png` или `.pdf` и SHALL показывать имя файла, а для растрового изображения — безопасное превью.

#### Scenario: Выбрано PNG-изображение разрешения

- **WHEN** пользователь выбирает корректный `.png` файл для типа UAE Residence Permit
- **THEN** система сохраняет его как текущий входной документ и показывает имя и превью изображения

#### Scenario: Выбран PDF разрешения

- **WHEN** пользователь выбирает корректный `.pdf` файл для типа UAE Residence Permit
- **THEN** система сохраняет его как текущий входной документ и показывает имя и обозначение PDF без передачи локального пути в UI

#### Scenario: Выбран неподдерживаемый формат

- **WHEN** пользователь пытается передать файл вне форматов JPG, JPEG, PNG и PDF
- **THEN** система отклоняет файл и сохраняет ранее собранные данные пользователя без изменений

### Requirement: Извлечение реквизитов UAE Residence Permit

Система SHALL извлекать из визуальных подписей документа `UID No`, `File No`, `Expiry Date`, `Profession` и `Employer` соответственно поля `residencepermitID`, `visaID`, `visaValidUntil`, `currentOccupation` и `employer`.

#### Scenario: Все требуемые значения распознаны

- **WHEN** пользователь запускает распознавание читаемого UAE Residence Permit с пятью требуемыми реквизитами
- **THEN** система возвращает все пять полей с соответствиями `UID No` → `residencepermitID`, `File No` → `visaID`, `Expiry Date` → `visaValidUntil`, `Profession` → `currentOccupation`, `Employer` → `employer`

#### Scenario: Отдельный реквизит не распознан

- **WHEN** документ распознан, но значение одного из требуемых реквизитов отсутствует или не может быть уверенно связано с его подписью
- **THEN** система возвращает для этого поля пустое значение и не подставляет соседний реквизит

#### Scenario: Присутствуют дополнительные реквизиты

- **WHEN** документ содержит имя, номер паспорта, место выдачи, дату выдачи или другие не запрошенные реквизиты
- **THEN** система не добавляет эти реквизиты в результат UAE Residence Permit

### Requirement: Нормализация распознанных значений

Система SHALL удалять служебные пробелы вокруг идентификаторов и текстовых значений, сохранять внутренние пробелы в профессии и работодателе и SHALL возвращать распознанный `visaValidUntil` в формате `YYYY-MM-DD` только для календарно корректной даты.

#### Scenario: Дата указана с разделителями

- **WHEN** `Expiry Date` распознана в поддерживаемом визуальном формате с `/`, `.` или `-`
- **THEN** система возвращает календарно корректную дату в формате `YYYY-MM-DD`

#### Scenario: Дата недействительна

- **WHEN** распознанное значение `Expiry Date` не образует календарно корректную дату
- **THEN** система возвращает пустой `visaValidUntil`, не подменяя его датой выдачи

### Requirement: Локальная и изолированная обработка

Система MUST обрабатывать UAE Residence Permit локально и MUST сохранять абсолютный путь и файловый доступ вне Angular renderer.

#### Scenario: Распознавание без сети

- **WHEN** приложение и OCR-ресурсы установлены, а подключение к сети отсутствует
- **THEN** пользователь может выбрать и распознать поддерживаемый UAE Residence Permit без удалённого API

#### Scenario: Ошибка OCR

- **WHEN** файл повреждён, не читается или OCR-процесс завершается ошибкой
- **THEN** UI показывает контролируемую ошибку без локального пути и сохраняет ранее собранные значения формы
