# Spec Delta

## ADDED Requirements

### Requirement: Англоязычное однопроходное распознавание разрешения

Система SHALL локально распознавать UAE Residence Permit за один OCR-проход, используя `PP-OCRv6_small_det` и `en_PP-OCRv5_mobile_rec`. Система MUST сохранять существующие проверки форматов идентификаторов и прежний контракт `ResidencePermitData`.

#### Scenario: Распознавание читаемого разрешения

- **WHEN** пользователь выбирает читаемый UAE Residence Permit
- **THEN** система применяет английский профиль и возвращает поддерживаемые поля без изменения внешнего формата результата

#### Scenario: Некорректный идентификатор

- **WHEN** OCR-кандидат не соответствует поддерживаемому формату идентификатора
- **THEN** система не возвращает его как валидное поле

#### Scenario: Автономная поставка

- **WHEN** приложение запускается без доступа к сети
- **THEN** детектор и английская recognition-модель загружаются из локального каталога поставки
