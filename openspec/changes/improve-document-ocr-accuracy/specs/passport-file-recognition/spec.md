# Spec Delta

## ADDED Requirements

### Requirement: Улучшенная однопроходная модель распознавания паспорта

Система SHALL локально распознавать российский паспорт за один OCR-проход, используя `PP-OCRv6_small_det` и `cyrillic_PP-OCRv5_mobile_rec`. Система MUST сохранять существующие проверки контрольных цифр MRZ и MUST возвращать прежний контракт `PassportData`.

#### Scenario: Распознавание читаемого паспорта

- **WHEN** пользователь выбирает читаемый файл российского паспорта
- **THEN** система выполняет один OCR-проход с паспортным профилем и извлекает поддерживаемые поля без изменения внешнего формата результата

#### Scenario: Некорректная MRZ

- **WHEN** распознанное структурированное значение не проходит проверку контрольной цифры MRZ
- **THEN** система возвращает для этого значения `None`, а не угадывает исправление

#### Scenario: Автономная поставка

- **WHEN** приложение запускается без доступа к сети
- **THEN** детектор и паспортная recognition-модель загружаются из локального каталога поставки
