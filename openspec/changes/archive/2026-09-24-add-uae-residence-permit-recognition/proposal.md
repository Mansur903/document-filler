# Proposal

## Why

Приложение распознаёт только российский заграничный паспорт и хранит результаты как данные одного файла, поэтому невозможно последовательно собрать сведения одного пользователя из паспорта и UAE Residence Permit. Нужно добавить второй тип документа, PNG и устойчивую общую форму, чтобы несколько локальных распознаваний дополняли один набор данных для DOCX-шаблона без потери уже полученных или введённых значений.

## What Changes

- Добавить выбор типа распознаваемого документа: российский заграничный паспорт или UAE Residence Permit (документ на приложенном образце, который в запросе назван Emirate ID).
- Добавить локальное распознавание UAE Residence Permit и вернуть `residencepermitID` из `UID No`, `visaID` из `File No`, `visaValidUntil` из `Expiry Date`, `currentOccupation` из `Profession` и `employer` из `Employer`.
- Добавить в общую форму пустые редактируемые поля `email`, `address` и `phone`; OCR не должен заполнять их автоматически.
- Объединить поля всех поддерживаемых документов в компактной прокручиваемой правой панели и сохранять значения между выборами и распознаваниями файлов.
- Поддержать распознавание паспорта и UAE Residence Permit в любом порядке и применить стратегию «первое непустое значение сохраняется»: каждое распознавание заполняет только относящиеся к нему пустые поля и не перезаписывает значения, уже полученные OCR или отредактированные вручную.
- Добавить отдельное действие «Новый пользователь», которое очищает общую форму и связанное с текущим пользователем состояние после подтверждения, если это требуется для защиты от случайной потери данных.
- Добавить `.png` в поддерживаемые форматы выбора, превью и локального OCR наряду с JPG, JPEG и PDF.
- Передавать все поля общей формы в генератор DOCX, чтобы новые плейсхолдеры были доступны шаблонам.

## Capabilities

### New Capabilities

- `uae-residence-permit-recognition`: выбор типа UAE Residence Permit, локальное OCR-распознавание полей документа и нормализация результата.
- `document-data-workspace`: единая редактируемая форма данных пользователя, правила неперезаписывающего слияния результатов, ручные контактные поля, явный сброс и генерация DOCX из совокупных данных.

### Modified Capabilities

- `passport-file-recognition`: добавить PNG в поддерживаемые входные форматы и изменить замену выбранного файла так, чтобы она не очищала уже собранные данные пользователя.

## Impact

- Angular: состояние формы и выбранного типа документа, компактная прокручиваемая панель, действие сброса, тексты и компонентные тесты.
- Electron: обобщённые модели выбранного документа и OCR-ответа, IPC/preload-контракт, фильтры файлов и безопасное хранение локального пути только в main process.
- Python OCR: маршрутизация по типу документа, парсер UAE Residence Permit, поддержка PNG, нормализация дат и набор тестовых фикстур/юнит-тестов.
- DOCX: расширенная модель данных и валидация плейсхолдеров `residencepermitID`, `visaID`, `visaValidUntil`, `currentOccupation`, `employer`, `email`, `address`, `phone` вместе с существующими полями, включая отдельный паспортный `validUntil`.
- Документация и сборка автономного `ocr.exe`: перечень форматов, типов документов, полей и проверка работы без сети.
