# Spec Delta

## MODIFIED Requirements

### Requirement: Supported passport file selection

Система SHALL позволять пользователю выбрать ровно один локальный файл `.jpg`, `.jpeg`, `.png` или `.pdf` через системный диалог. Выбор, замена или отмена выбора MUST NOT очищать значения, уже сохранённые в общей форме данных пользователя.

#### Scenario: Select a JPEG passport image

- **WHEN** пользователь выбирает файл `.jpg` или `.jpeg`
- **THEN** система сохраняет его как текущий входной файл паспорта и показывает имя и превью изображения без очистки общей формы

#### Scenario: Выбор PNG-изображения паспорта

- **WHEN** пользователь выбирает файл `.png`
- **THEN** система сохраняет его как текущий входной файл паспорта и показывает имя и превью изображения без очистки общей формы

#### Scenario: Select a PDF passport document

- **WHEN** пользователь выбирает файл `.pdf`
- **THEN** система сохраняет его как текущий входной файл паспорта и показывает имя и тип PDF без очистки общей формы

#### Scenario: Cancel passport file selection

- **WHEN** пользователь отменяет системный диалог выбора
- **THEN** система оставляет текущий входной файл паспорта и значения общей формы без изменений

#### Scenario: Replace the selected passport file

- **WHEN** пользователь выбирает другой поддерживаемый файл паспорта
- **THEN** система заменяет текущий входной файл и сохраняет все значения общей формы

### Requirement: Minimal renderer access

Система MUST хранить локальный путь выбранного файла и доступ к файловой системе вне Angular renderer и SHALL передавать в UI только имя, тип файла и необходимые данные превью.

#### Scenario: PDF metadata is returned to Angular

- **WHEN** выбран PDF
- **THEN** Angular не получает локальный путь и неограниченные возможности Node.js или Electron

#### Scenario: JPEG preview is returned to Angular

- **WHEN** выбрано изображение JPG или JPEG
- **THEN** Angular получает безопасные данные превью без локального пути

#### Scenario: Превью PNG передано в Angular

- **WHEN** выбрано изображение PNG
- **THEN** Angular получает безопасные данные PNG-превью с корректным media type и без локального пути

### Requirement: Passport recognition from supported files

Система SHALL запускать существующий локальный OCR паспорта для выбранного JPG, JPEG, PNG или PDF и возвращать в Angular существующие структурированные поля паспорта. Возвращённые поля SHALL объединяться с общей формой без перезаписи её непустых значений.

#### Scenario: Recognize a JPEG passport image

- **WHEN** пользователь запускает распознавание выбранного JPG или JPEG паспорта
- **THEN** система извлекает данные с прежней семантикой и объединяет только непустые результаты с пустыми полями общей формы

#### Scenario: Распознавание PNG-изображения паспорта

- **WHEN** пользователь запускает распознавание выбранного PNG паспорта
- **THEN** система извлекает и объединяет данные с той же семантикой полей, что для JPG и JPEG

#### Scenario: Recognize a single-page passport PDF

- **WHEN** пользователь запускает распознавание корректного одностраничного PDF со сканом паспорта
- **THEN** система извлекает поддерживаемые поля из отрисованной страницы и объединяет только непустые результаты с пустыми полями общей формы

#### Scenario: Recognize a passport PDF with photo and signature pages

- **WHEN** пользователь запускает распознавание корректного PDF со страницами фотографии и подписи паспорта
- **THEN** система определяет страницу фотографии по MRZ российского паспорта, извлекает поля только с неё, игнорирует страницу подписи и объединяет только непустые результаты с пустыми полями общей формы

#### Scenario: PDF cannot be processed

- **WHEN** выбранный PDF повреждён, не читается, зашифрован без доступа или не содержит отображаемого содержимого
- **THEN** распознавание завершается контролируемой ошибкой без раскрытия локальных путей Angular, а значения общей формы остаются без изменений

#### Scenario: Изображение невозможно обработать

- **WHEN** выбранное JPG, JPEG или PNG повреждено, не читается или не содержит распознаваемого изображения
- **THEN** распознавание завершается контролируемой ошибкой без раскрытия локальных путей Angular, а значения общей формы остаются без изменений
