# Proposal

## Why

Приложение распознаёт российский заграничный паспорт, но внутренний паспорт РФ имеет другие страницы, подписи и формат номера. При выборе такого скана действующий парсер загранпаспорта не извлекает его данные, поэтому пользователю приходится заполнять форму вручную.

## What Changes

- Добавить отдельный тип документа `Russian Internal Passport` в явный выбор перед распознаванием; существующий тип показать в интерфейсе как `Russian Foreign Passport` и сохранить его прежнее поведение.
- Локально распознавать разворот с данными о выдаче и владельце из JPG, JPEG, PNG или PDF, включая файлы с несколькими страницами.
- Извлекать фамилию, имя, отчество, пол, дату и место рождения, серию и номер паспорта, дату выдачи, код подразделения и орган выдачи. Неоднозначные или отсутствующие значения оставлять пустыми для ручной проверки.
- Добавить отдельные редактируемые поля `patronymic`, `internalPassportSeries`, `internalPassportNumber`, `subdivisionCode` в общую форму и DOCX-плейсхолдеры; общие персональные поля и реквизиты выдачи заполнять по существующему правилу без перезаписи.
- Проверять новый результат на границе Electron IPC и покрыть парсер, маршрутизацию, объединение данных и генерацию DOCX тестами с вымышленными значениями.

## Capabilities

### New Capabilities

- `russian-internal-passport-recognition`: выбор типа, локальное распознавание страниц внутреннего паспорта РФ, состав и проверка извлекаемых реквизитов.

### Modified Capabilities

- `document-data-workspace`: новые поля внутреннего паспорта, объединение с результатами других документов и передача значений в DOCX.

## Impact

- Python OCR: отдельный парсер внутреннего паспорта, маршрутизация по типу документа, модели результата и тесты. Предполагается повторное использование имеющегося кириллического профиля PaddleOCR без новой зависимости.
- Electron: тип документа, проверка структуры OCR-ответа и доступность новых полей для генератора DOCX.
- Angular: третий вариант выбора типа, уточнённая подпись загранпаспорта, новые поля общей формы и компонентные тесты.
- Документация плейсхолдеров и ручной проверки распознанных данных. Образец из запроса используется только для понимания структуры разворота; персональные данные образца не включаются в репозиторий или тестовые фикстуры.
