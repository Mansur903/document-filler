# Spec Delta

## MODIFIED Requirements

### Requirement: Единая панель данных пользователя

Система SHALL постоянно показывать в правой панели все поля российского заграничного паспорта, включая редактируемое строковое поле `authority`, все поля UAE Residence Permit и ручные поля `email`, `address`, `phone` независимо от того, какие документы уже распознаны. Панель SHALL использовать компактное расположение полей и собственную вертикальную прокрутку при нехватке высоты, не скрывая доступ к выбору и распознаванию документа.

#### Scenario: Форма открыта до первого распознавания

- **WHEN** пользователь открывает приложение для нового пользователя
- **THEN** правая панель показывает все поддерживаемые поля пустыми, включая `authority`, `email`, `address` и `phone`

#### Scenario: Поля не помещаются по высоте

- **WHEN** высота окна недостаточна для одновременного отображения всех полей
- **THEN** пользователь может прокрутить правую панель и получить доступ к каждому полю без прокрутки или исчезновения панели выбора документа

#### Scenario: Значение отредактировано вручную

- **WHEN** пользователь изменяет любое поле общей формы, включая `authority`
- **THEN** отредактированное значение немедленно становится текущим значением для дальнейшего слияния и генерации документа

#### Scenario: Распознан орган выдачи паспорта

- **WHEN** паспортный OCR возвращает непустое `authority`, а одноимённое поле общей формы пусто
- **THEN** система показывает распознанный орган выдачи в редактируемом input `authority`

### Requirement: Генерация DOCX из общей формы

Система SHALL передавать в выбранный DOCX-шаблон все существующие паспортные поля, включая `authority`, и поля `residencepermitID`, `visaID`, `visaValidUntil`, `currentOccupation`, `employer`, `email`, `address`, `phone`, используя текущие отредактированные значения общей формы. Для паспортной даты `validUntil` и даты разрешения `visaValidUntil` SHALL применяться существующее форматирование даты DOCX.

#### Scenario: Шаблон содержит новые плейсхолдеры

- **WHEN** пользователь генерирует документ из шаблона с поддерживаемыми плейсхолдерами, включая `{authority}`
- **THEN** каждый плейсхолдер заменяется текущим значением одноимённого поля общей формы

#### Scenario: Поле осталось пустым

- **WHEN** плейсхолдер присутствует в шаблоне, но соответствующее поле общей формы пусто
- **THEN** генератор обрабатывает его по единому действующему правилу для пустых значений и не использует данные из предыдущего пользователя
