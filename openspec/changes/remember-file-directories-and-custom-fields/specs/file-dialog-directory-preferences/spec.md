# Spec Delta

## Purpose

Определяет, как настольное приложение запоминает последние папки выбора входного документа и DOCX-шаблона, чтобы повторные системные диалоги открывались в ожидаемом месте.

## ADDED Requirements

### Requirement: Отдельные последние папки выбора файлов

Система SHALL запоминать папку последнего успешно выбранного входного документа и папку последнего успешно выбранного DOCX-шаблона как две независимые настройки. При следующем открытии соответствующего системного диалога система SHALL предлагать сохранённую папку, в том числе после перезапуска приложения.

#### Scenario: Повторный выбор документа

- **WHEN** пользователь успешно выбирает паспорт или UAE Residence Permit из папки `A`, а затем повторно открывает диалог выбора документа
- **THEN** диалог выбора документа открывается в папке `A`

#### Scenario: Повторный выбор шаблона

- **WHEN** пользователь успешно выбирает DOCX-шаблон из папки `B`, а затем повторно открывает диалог выбора шаблона
- **THEN** диалог выбора шаблона открывается в папке `B`

#### Scenario: Папки разных диалогов не смешиваются

- **WHEN** пользователь выбирает документ из папки `A`, а шаблон из папки `B`
- **THEN** диалог выбора документа использует папку `A`, а диалог выбора шаблона — папку `B`

#### Scenario: Приложение открыто повторно

- **WHEN** приложение перезапущено после успешного выбора документа и шаблона
- **THEN** оба диалога используют свои последние сохранённые папки

### Requirement: Безопасное обновление и использование последних папок

Система MUST обновлять соответствующую последнюю папку только после успешного принятия файла. Отмена выбора или ошибка MUST оставлять обе сохранённые папки без изменений. Если сохранённая папка больше недоступна, система SHALL открывать диалог в стандартном расположении без блокировки выбора файла. Абсолютные пути сохранённых папок MUST оставаться вне Angular renderer.

#### Scenario: Выбор отменён

- **WHEN** пользователь закрывает любой диалог выбора без файла
- **THEN** сохранённые последние папки не меняются

#### Scenario: Файл не принят

- **WHEN** выбранный файл отклонён как неподдерживаемый или не может быть открыт
- **THEN** последняя папка соответствующего диалога не меняется

#### Scenario: Сохранённая папка удалена

- **WHEN** сохранённой папки больше нет или она недоступна
- **THEN** системный диалог открывается без этой папки и позволяет выбрать новый файл

#### Scenario: Данные выбора передаются в интерфейс

- **WHEN** пользователь выбирает документ или шаблон
- **THEN** Angular получает только предусмотренные метаданные файла и не получает абсолютный путь сохранённой папки
